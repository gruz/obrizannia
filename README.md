# Mp4TailWatcher

Фонова Windows-програма в системному треї. Побачить новий `.mp4` у теці —
створить поруч `назва_last30.mp4` (останні N секунд) і покаже сповіщення.
Клік по сповіщенню відкриває Провідник із уже виділеним файлом.

## Швидкий старт

1. Завантаж `Mp4TailWatcher.exe` зі сторінки [Releases](https://github.com/gruz/obrizannia/releases).
2. Запусти — іконка з'явиться в треї. Перший запуск створить поруч
   `Mp4TailWatcher.ini` і, при потребі, завантажить `ffmpeg.exe`.
3. Кидай `.mp4` у теку — поруч з'явиться `*_last30.mp4`.

## Меню трею

Права кнопка по іконці:

- **Open watch folder** — відкрити теку спостереження
- **Open last output** — відкрити останній згенерований файл
- **Check for updates** — перевірити оновлення на GitHub
- **Settings...** — змінити теку, кількість секунд і режим зрізу
- **Exit** — вихід

Інтерфейс автоматично українською, якщо Windows має українську мову
відображення, інакше англійською.

## Налаштування (`Mp4TailWatcher.ini`)

| Параметр | За замовчуванням | Опис |
|---|---|---|
| `WatchDir` | Downloads | Тека для спостереження |
| `Seconds` | 30 | Скільки секунд з кінця лишати |
| `KeyframeFast` | true | true — швидко по ключовому кадру; false — точно з перекодуванням |
| `FfmpegUrl` | ffbinaries @ GitHub | Джерело ffmpeg для першого запуску |
| `UpdateRepo` | gruz/obrizannia | GitHub-репо для перевірки оновлень |

## Примітки

- Програма дозволяє лише один запущений екземпляр.
- Windows може попереджати SmartScreen — exe непідписаний. Щоб цього
  уникнути, потрібен code signing certificate.
- Події та помилки пишуться в `Mp4TailWatcher.log` поруч з exe.
- `build.bat` збирає exe локально через `csc.exe` (потрібен .NET Framework 4.x).
  Готовий реліз збирає GitHub Actions при пуші тегу `v*`.
